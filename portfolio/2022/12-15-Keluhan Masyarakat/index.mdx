**Keluhan Masyarakat** is a community service project dedicated towards Tanjung Sari Ward, Batam, Indonesia to support the needs in public feedbacks/complaints media towards local government.

This project was built using the CodeIgniter3 framework and Bootstrap 5 with MVC design pattern.

<Callout Color="bg-gray-300 border-l-gray-300">The detail of the implementation is explained in this <a href="https://journal.uib.ac.id/index.php/nacospro/article/view/8036" target="_blank">community service paper</a>.</Callout>

<!-- truncate -->

## Problem Statement:

To assist the “Digital Village” program from the Ministry of Villages, Development of Disadvantaged Regions and Transmigration (Kementerian Desa, Pembangunan Daerah Tertinggal, dan Transmigrasi), digitalization need to be strengthened from the village level to support information systems development.

This project functions as a digital service that is expected to be able to assist village development from various aspects, particularly the use of information and communication technology.
